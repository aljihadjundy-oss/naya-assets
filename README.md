# Naya Assets

Reference pack for **Naya (Serena Nayanika)**, AI avatar/persona. Dipakai sebagai reference untuk generate konten (image gen / GPT).

Raw URL pattern: `https://raw.githubusercontent.com/aljihadjundy-oss/naya-assets/main/<path>`
Daftar lengkap semua file + URL: [`manifest.json`](manifest.json)

## Struktur

| Folder | Isi | Dipakai untuk |
|---|---|---|
| `01_Avatar` | Avatar (varian anting) | Identity reference wajah |
| `02_Angle-Shots` | Front, profile kiri/kanan, 3/4, look up/down, high/low angle, close-up | Konsistensi wajah dari berbagai angle |
| `03_Body-Outfit` | Torso, full body signature cream, casual linen-denim | Proporsi tubuh dan outfit |
| `04_Hair-Turnaround` | 14 sheet gaya rambut (front/left/back/right) | Variasi gaya rambut |
| `05_Expressions` | Sheet 20 ekspresi, plus 3 sheet (positif, netral, negatif) | Variasi ekspresi |
| `06_Apartment` | Living room (v1, v2-ArcLamp), workspace, bedroom, kitchen, balcony, bathroom | Setting apartemen Jaksel |
| `07_Pose-Reference` | 42 referensi pose OOTD (standing, sitting, mirror selfie, close-up selfie, candid, detail) | Pose, framing, komposisi saja |

`07_Pose-Reference/_INDEX.md` berisi deskripsi tiap referensi pose.

## Catatan pemakaian
- Wajah, kulit, dan rambut Naya selalu dari `01_Avatar` + `02_Angle-Shots`.
- `07_Pose-Reference` hanya untuk pose, gerakan, dan komposisi. Jangan ambil wajah atau identitas dari foto di folder itu.
- Living room pakai `v2-ArcLamp` sebagai versi utama.

## Karakter
Tenang tapi tajam, execution-first, elegan, hangat. Palet: cream, terracotta, sage, brass.
